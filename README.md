# VENOM - SLiMS 9 OPAC Template

Template OPAC modern, responsif, dan kaya fitur untuk SLiMS 9 Bulian.

## 🚀 Fitur Utama
- Desain responsif (Mobile-First)
- Widget Waktu Sholat & Chat Widget terintegrasi
- Navigasi bawah khusus mobile (Mobile Bottom Nav)
- Dukungan multi-bahasa (ID/EN)
- Format sitasi lengkap (APA, MLA, Chicago, Turabian)

## 📋 Kebutuhan Sistem
- SLiMS 9 Bulian (v9.8.0 atau lebih baru)
- PHP 7.4 atau 8.x
- MySQL/MariaDB

## 📁 Struktur Folder
- `assets/` : CSS, JS, Gambar, dan Plugin pihak ketiga.
- `citation/` : Template format kutipan bibliografi.
- `helpers/` : Fungsi bantu (core, UI, security, options).
- `parts/` : Komponen UI yang dapat digunakan kembali (header, footer, modal, dll).

## 🛠️ Instalasi
1. Unduh atau clone repositori ini.
2. Salin seluruh isi folder ke dalam direktori `template/venom` di instalasi SLiMS Anda.
3. Masuk ke Panel Admin SLiMS > **Pengaturan Sistem** > **Pengaturan Tampilan**.
4. Pilih **venom** sebagai tema aktif.
